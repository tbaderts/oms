## Goal Assessment

The Goal: the FIX execution report's instrument block is mandatory (symbol or securityId), the
execution should have whatever came back from the exchange/simulator, and the simulator should add
it if it is missing. All three hold:

- executions carry `symbol`, `securityId`, `securityIdSource` as the venue reported them, through
  REST, Kafka, storage and `oms_executions`;
- a fill without an instrument is refused, as is one that contradicts its order;
- the exchange simulator now sends the order's instrument on every fill.

Left out on purpose (proposal scope): the rest of the FIX Instrument block, symbology mapping, and
moving the streaming execution stream onto `oms_executions` (SPEC-0071). Until SPEC-0071 the live
blotter's symbol comes from `oms_order_executions`, i.e. the order's, which equals the fill's for
every applied fill because a mismatch is refused.
