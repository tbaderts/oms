# Developer

A person building the OMS who reads its specifications, runs it locally and tests it against the simulator.

## Responsibilities

- Reads capabilities, specifications and decisions.
- Runs the stack and the exchange simulator.
- Writes spec tickets and keeps the knowledge base current.
